# 实践工坊内容扩展

独立入口为 `/workshop/`，各语言使用 `/{locale}/workshop/`。原有手册、自测和日课不因增加工坊内容而改变。首批包括 8 个虚构场景案例、4 份可填写练习表和 6 个利益、激励与边界专题。

## 添加内容

编辑 `content/workshop/zh-CN.json`，并同步 `zh-TW`、`en`、`ja`、`ko`、`de`、`ru`、`es`、`fr` 八份译文。类型见 `src/lib/workshop/types.ts`。

- `cases`：新增唯一 `id`、分类、情境、问题、选项及其取舍分析、原则、行动和回看问题；`template` 引用练习表 ID，`chapter` 引用现有章节 slug。案例不进行人格评分，也不假称真实人物的经历。
- `templates`：新增唯一 `id`、标题、说明与 `fields`。每个字段使用稳定 ID、名称、提示。更改已发布 ID 会影响历史记录关联，应保留已有 ID；新增字段时旧记录仍可读取。
- `topics`：新增唯一 `id`、标题、核心观点、问题列表、示例与适用边界。
- 内容数组驱动页面，新增条目不需要复制页面组件。新增第四类模块时，在视图中增加独立 section，并同步模块导航与语言内容。

不要把翻译后的显示文字当作存储 ID。不要在案例中写入真实用户、客户或公司的私密记录。

## 数据行为

工坊使用独立的 `dq.workshop.v1` 本地存储键，各语言共用。四种练习各有一份自动保存的草稿；保存记录会留下快照，不会清空草稿。用户原文不会自动翻译。

当前草稿可导出为 Markdown，全部草稿和记录可导出为 JSON。导入仅支持版本 1 和不超过 10 MB 的文件；保留现有草稿、合并记录、去除相同记录。相同 ID 内容冲突、格式错误或不支持的版本会拒绝整个导入。未知的未来字段保留在备份中。

保存失败时页面明确提示，保留当前输入供导出；已有本地数据损坏时不覆盖原值，并提供原始数据导出。清空草稿、删除记录或用记录替换草稿均需用户确认。此功能无账号、服务器写入或分析上报；网页版与 Windows 本地地址各自独立。

## 验证与发布

运行 `npm run test:i18n`、`npm run test:workshop`、`npm run lint`，并分别构建 Pages 与 Windows 静态版本。新增内容后更新首批数量测试为实际数量。

检查所有语言的结构、非空内容、稳定 ID、关联章节和练习表；再用浏览器检查筛选、选项反馈、自动保存、刷新、切换语言、历史记录、备份导入导出及窄屏布局。结构检查不替代母语编辑审校。

GitHub 介绍页维持简体中文、繁体中文、English、日本語四版。网站与 Windows Release 应基于同一份已验证源码发布。
