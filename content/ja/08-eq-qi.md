## 感情はデータである

賢い人は時に、感情を理性の邪魔になる雑音として、抑え込むべきものと考えます。しかし、神経科学が示す姿はそれほど単純ではありません。

アントニオ・ダマシオは、感情処理に関わる領域を損傷した患者を研究しました。知能検査や論理的推論の能力は保たれていても、日常の意思決定が非常に難しくなることがありました。面会の日程を決めるだけで三十分かかることさえあります。選択肢に重みを感じる手がかりを失い、どれも同じように見えるためです。

感情は単なる雑音ではなく、データです。恐怖は危険を、怒りは境界線の侵害を、恥は集団の規範との距離を、喜びは大切なものを知らせることがあります。問題は感情があることではなく、**そのメッセージを理解し、従うかどうかを決めること**です。

感情の道具は、そのデータを読み取るための器具です。

## 1. 感情の語彙表

心理学者リサ・フェルドマン・バレットの研究では、感情を細かく区別する力と、感情調整との関係が示されています。単に「気分が悪い」と言う代わりに、いら立ち、理不尽さ、侮辱された感じ、やり場のない憤りを区別します。名づけることが、調整の始まりになります。

手元に語彙表を置きましょう。まずは次の一覧から始められます。

| 系統 | 比較的弱いものから強いものまでの表現 |
| --- | --- |
| 怒り | 不満、いら立ち、腹立たしさ、理不尽さ、侮辱された感じ、憤り、激怒、恨み |
| 恐れ | 落ち着かなさ、気がかり、心配、不安、動揺、恐怖、絶望 |
| 悲しみ | 失望、残念さ、孤独、傷ついた感じ、悲哀、悲痛、感覚の麻痺 |
| 喜び | 安心感、安堵、くつろぎ、感謝、喜び、有頂天 |
| 恥と罪悪感 | 気まずさ、ばつの悪さ、罪悪感、羞恥、自責 |
| 比較 | 憧れ、羨望、負けを認めたくない気持ち、優越感 |
| 混合 | 感謝しつつ重荷を感じる、楽しみだが怖い、ほっとしながら少し残念 |

使い方は簡単です。一日一回以上立ち止まり、今の気持ちに**最も正確な言葉**を選びます。言いやすい言葉ではなく、ぴったりの言葉を選んでください。

## 2. 身体スキャンと呼吸

感情は意識に上る前に、身体に現れることがあります。胸の締めつけ、食いしばった顎、汗ばんだ手、胃が沈む感じなどです。身体を読めると、数秒早く気づく余地が生まれます。

**身体スキャン：** 目を閉じ、頭から足へ注意を移しながら、どこが緊張しているかを確かめます。三十秒で十分です。

**呼吸：** 簡単な方法を二つ紹介します。
- 生理的ため息：短く二回吸います。二回目は一回目に少し足すように吸い、その後長く吐きます。二、三回繰り返します。
- 4・7・8呼吸：四秒吸い、七秒止め、八秒かけて吐きます。四回繰り返します。

これで感情が消えるわけではありません。感情に押されている状態から、それを観察できる状態へ移る助けになります。この違いが、後の技術の土台になります。

## 3. 感情日記

毎日一件、決まった形式で記録します。

**きっかけ**（何が起きたか）→ **身体**（どこに感じたか）→ **感情**（正確に名づける）→ **思考**（頭の中の一文）→ **行動**（何をしたか）→ **ニーズ**（本当は何を求めていたか）。

一か月後に読み返すと、似たきっかけ、身体反応、考え、行動が見えてきます。型を変える前に、まず型を見る必要があります。それが、第11章で扱う自己理解の始まりです。

## 4. 一時停止ボタン

刺激と反応の間には隙間があり、その隙間に自由がある。この考えはしばしばヴィクトール・フランクルに帰されますが、正確な出典は別として、一時停止の意味をよく表しています。

一時停止ボタンとは、その隙間を意図して広げるものです。形はいろいろあります。

- 身体の動作：水を飲む、立ち上がる、スマートフォンを伏せる。
- 決まった一言：「少し考えてから、後で返事をします」。
- ルール：動悸がするようなメッセージには、十分以内に返信しない。

感情が生じた直後の身体的な高まりは、一、二分で弱まることもあります。一時停止の狙いは、その最初の波を自動的な行動に変えずにやり過ごすことです。

## 5. ニーズの一覧

マーシャル・ローゼンバーグの非暴力コミュニケーションの中心には、**感情の背後にはニーズがある**という考えがあります。怒りの背後には尊重、不安の背後には見通し、傷つきの背後には自分を見てもらいたい気持ちがあるかもしれません。

感情は信号であり、ニーズはその内容です。一覧を使って、信号を言葉に訳します。

尊重・認められること・理解・安全・自律・所属・公正・見通し・意味・成長・休息・信頼・貢献・親密さ・一人になれる余地

強い感情に名前をつけたら、それがどのニーズを伝えているかを問います。ニーズが分かれば、「腹が立つ」から「尊重されたい」へ進めます。後者は具体的に伝えられますが、前者だけでは爆発に終わるかもしれません。

## 6. 関係の帳簿

人生で大切な十人から十五人を挙げます。それぞれについて定期的に二つ記録します。**最近の預け入れ**は、具体的な感謝、守った約束、注意深く聴いたこと。**最近の引き出し**は、破った約束、きつい言葉、放置したことです。

賢い人は、関係を「営むもの」ではなく「持っているもの」と考えがちです。帳簿をつけると、親しいつもりの相手に三か月も預け入れをしていないと気づくかもしれません。

## 三つの原則

**1. 消すためでなく、見るために使う。** 目的は感情をなくすことではなく、感じながら明瞭に見ることです。一度も怒らないことが成熟とは限りません。感度が低いだけの場合もあります。

**2. 他人より先に自分に使う。** 自分の語彙、身体、日記、ニーズから始めます。自分を読めないまま他人を読もうとすると、投影になりかねません。

**3. 記録したら、振り返る。** 思考の道具と同じです。読み返さない感情記録は、整った愚痴帳になってしまいます。

## 器から術へ

一覧を見なくても「怒りというより理不尽さだ」と分かる。胸が締まる最初の瞬間に、指示がなくても立ち止まる。怒っていても、チェックリストなしに本当のニーズを問える。そうなると、道具は後景に退き、技術が現れます。

次の章では、その技術を扱います。
